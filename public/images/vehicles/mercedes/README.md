# Mercedes-Benz vehicle image assets

This directory is the production home for the Mercedes-Benz fleet photography.

The current standalone HTML build uses the filenames below as primary image paths and falls back to hosted automotive photography until model-specific generated photographs are added.

Required visual brief for every final image:

- Photorealistic professional automotive photography, not an illustration or 3D render.
- Landscape 3:2 composition, full vehicle visible, centered 3/4 front angle, breathing room.
- Clean bodywork, realistic reflections, headlights, wheels and tires.
- No people, readable license plates, dealership logos, watermarks, random text, or distorted proportions.
- Dark luxury studio, light-gray studio, premium architecture, hotel/resort, or subtle scenic road background.
- Consistent camera height, color treatment, and premium dark/white/gold rental-site language.

See `mercedes-image-prompts.md` and `mercedes-image-manifest.json` for the per-model briefs.
